\# Diseño de Base de Datos



\## Descripción



El sistema \*\*Go Digital Library\*\* utilizará una base de datos externa PostgreSQL para almacenar la información de libros, usuarios y préstamos.



El uso de PostgreSQL permitirá que la información sea persistente, es decir, que los datos no se pierdan al cerrar la aplicación.
